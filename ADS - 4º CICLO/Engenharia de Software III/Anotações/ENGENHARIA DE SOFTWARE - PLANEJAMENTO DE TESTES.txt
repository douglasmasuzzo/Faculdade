- IMPORTÂNCIA
 
 -> Quem faz?
  + o planejamento é executado pelo gerente / engenheiros de softwares e especialistas de testes
  
 -> Por que é importante?
  + o teste enfatiza principalmente a avaliação de qualidade do produto 
  + localizar e documentar defeitos na qualidade de software
  + avaliar forma geral sobre a qualidade de software
  + validar suposições de especificações e requisitos em demonstração correta
  + validar funções de softwares planejados
  + verificar se os requisitos foram implementados

- EXEMPLO DE ERRO DE SITUAÇÃO 

 -> você faz o levantamento de requisitos funcionais e não-funcionais 
 -> os responsáveis analisam e verificam os padrões de formações de documentações ( UML )
 -> o processo é aprovado e é direcionado ao processo de desenvolvimento
 -> o repasse continua para a área de qualidade de testes ( QA ), que também valida todo o processo de teste conforme os documentos criados anteriormente
 -> a homologação é direcionada ao cliente
 -> e o cliente revoga os processos e etapas de desenvolvimento de inconsistente, considerando os modelos de testes e construção oficializado pela empresa
