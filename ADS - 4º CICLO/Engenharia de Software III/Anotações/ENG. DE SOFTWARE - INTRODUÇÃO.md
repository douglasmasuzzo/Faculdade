## MATÉRIA DE PROVA : ARQUITETURA DE SOFTWARE ##

 - O QUE É UMA ARQUITETURA DE REFERÊNCIA?
    > Uma **Arquitetura de Referência** é um modelo padronização que serve como guia para o desenvolvimento de soluções dentro de um domínio específico.  É um conjunto de práticas, padrões e diretrizes testadas que orientam durante a estruturação do sistema.

    > Geralmente, o mecanismo documenta Padrões Arquiteturais como escolhas de Microsserviços, Event-Driven ou Arquitetura em Camadas. Inclui Componentes Reutilizáveis, Diretrizes sobre o fluxo e comunicação de dados dentro do sistema e uso de vocabulário geral.
